RYCHLÉ PROHLÉDNUTÍ
1. Rozbalte ZIP.
2. Otevřete terminál ve složce aterint-web.
3. S nainstalovaným Pythonem 3 spusťte:
   python -m http.server 8080 --directory public
4. V prohlížeči otevřete http://localhost:8080
   Na Windows lze místo python použít py.
   Server ukončíte Ctrl+C. HTML neotvírejte přímo dvojklikem;
   web používá adresy souborů od kořene serveru.

ÚPRAVY A SESTAVENÍ
Změňte zdrojáky v src/ nebo šablony a kontakty v scripts/generate.py.
Potom spusťte:
   python scripts/generate.py
Pro kontrolu použijte Node.js 22 nebo novější:
   node scripts/check-motion.mjs
   node scripts/check-site.mjs
Serverové sestavení v prostředí s Bash (např. Linux, macOS nebo WSL):
   bash scripts/build.sh
   node scripts/validate-artifact.mjs
Instalace npm balíčků není potřeba.

VLASTNÍ DOMÉNA ATERINT.COM
Výchozí export odpovídá pracovnímu webu na Sites a má zakázanou indexaci.
Před skutečným nasazením na aterint.com vytvořte produkční výstup:
   python scripts/generate.py --production --origin https://aterint.com
Na vlastní hosting nahrajte obsah public/. Podrobný postup, HTTPS,
přesměrování a kontroly bezpečnostních hlaviček jsou v README.md.
Součástí archivu nejsou účty hostingu, přístupové tokeny ani DNS nastavení.
Fotografie a video jsou webové podklady projektu; nejde o původní
neupravené kamerové soubory nebo samostatný soubor návrhu ve Figmě.

GITHUB PAGES
Repozitář obsahuje workflow .github/workflows/pages.yml. Každý push do
větve main web automaticky sestaví a zveřejní na
https://rhadek.github.io/aterint-web/ (pracovní verze bez indexace).
Jednorázově je potřeba v GitHubu: Settings → Pages → Source: GitHub Actions.
Vlastní doména: Settings → Secrets and variables → Actions → Variables
→ CUSTOM_DOMAIN = aterint.com, potom Settings → Pages → Custom domain
a u registrátora domény nastavit DNS podle návodu GitHubu.
